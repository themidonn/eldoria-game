# 🗡️ Хроники Эльдории

<!-- region ОПИСАНИЕ -->
Zelda-like игра на Python с использованием Pygame-CE.
Работает и локально (`python main.py`), и прямо в браузере (через Pygbag).

## 📖 Сюжет
Тёмный лорд Морвейн похитил Священное Пламя Эльдории. Без него земля
угаснет, а тьма поглотит всё живое. Вы — последний странник, способный
вернуть свет.

Найдите Старейшину в деревне — он расскажет о задании. Соберите три
Кристалла Света (в лесу, у озера и в древних руинах), вернитесь к
Старейшине — он откроет ворота замка на северо-западе. Победите
Морвейна и верните Пламя.

По пути исследуйте древние камни (они рассказывают историю мира),
выполните побочный квест жителя деревни и загляните в подземелье под
деревенским колодцем — там вас ждёт Король Скелетов и сундук с наградой.

## 🕹️ Управление

### В игре
| Клавиша | Действие |
|---|---|
| **WASD / Стрелки** | Движение |
| **Space / J** | Удар мечом |
| **E** | Взаимодействие (NPC, лор-камни, лестницы, сундук) |
| **F5** | Сохранить игру |
| **ESC** | Пауза (ESC повторно — продолжить) |
| **Q** | Выход из игры (только в меню паузы) |

### В диалогах
| Клавиша | Действие |
|---|---|
| **Space / Enter** | Следующая страница |
| **Y / N** | Ответ Да / Нет (только в диалогах с выбором) |
| **Esc** | Закрыть диалог (кроме диалогов с выбором) |

### На экране вступления
| Клавиша | Действие |
|---|---|
| **Space / Enter** | Следующая страница |
| **Esc** | Пропустить вступление |

### На титульном экране
| Клавиша | Действие |
|---|---|
| **Enter** | Продолжить (если есть сохранение) |
| **N** | Начать новую игру (удаляет сохранение) |
| **Любая клавиша** | Начать новую игру (если сохранения нет) |

### После победы или поражения
| Клавиша | Действие |
|---|---|
| **R** | Начать новую игру с нуля (сохранение удаляется) |

## ✨ Что в игре
- **Большой открытый мир (180×130 тайлов)** — с густым лесом, горной грядой на севере (с проходами-ущельями) и опасным болотом на юго-западе.
- **3 Кристалла Света** — охраняются слизнями (обычные 2 HP, элитные 3 HP в руинах).
- **Побочный квест:** житель деревни потерял ключ — найдите его в лесу и получите стальной клинок (урон ×2).
- **5 лор-камней** — прочитайте все и получите +1 к максимальному HP.
- **Подземелье** — вход через колодец в деревне. Летучие мыши, скелеты-стражи, босс **Король Скелетов** (30 HP, вторая фаза с ускорением, учащённой стрельбой костяными копьями и красными глазами) и сундук с полным лечением после победы. Внутри — 3 древних камня с лором.
- **Босс Морвейн** — 20 HP, фазы преследования и **рывка с 0.5-секундным телеграфом** (босс мигает и показывает направление атаки, давая время уклониться).
- **Эффекты:** тряска камеры, частицы при смерти врагов, всплывающие цифры урона, красная виньетка при низком HP.

## 🚀 Как запустить локально
1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Запустите игру:
```bash
python main.py
```

<!-- region ТЕХНОЛОГИИ -->
## 🛠️ Технологии
- **Python 3.12** — язык
- **Pygame-CE** — игровой движок
- **Pygbag** — компиляция Python в WebAssembly для браузера
- **asyncio** — асинхронный главный цикл (требование Pygbag)
- **GitHub Actions** — автодеплой веб-версии на GitHub Pages при каждом push
- **Tiny5** — пиксельный шрифт с поддержкой кириллицы (лицензия OFL)

<!-- region СОХРАНЕНИЯ -->
## 💾 Сохранения

Прогресс сохраняется автоматически при:
- подборе кристаллов и ключа,
- прочтении лор-камней,
- выполнении квестов,
- открытии сундука,
- победе над боссом,
- переходе между уровнями.

**Зелья не сохраняются** — если погибнете, они появятся на карте заново.

Вручную — клавишей **F5** (в игре или в меню паузы).

На титульном экране: **Enter** — продолжить, **N** — новая игра.
