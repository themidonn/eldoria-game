# 🗡️ Хроники Эльдории

Zelda-like игра, написанная на Python с использованием Pygame. 

## 🎮 Играть онлайн
Вы можете поиграть в игру прямо в браузере (не требуется установка Python):
👉 **[Играть в Хроники Эльдории](https://themidonn.github.io/eldoria-game/)**

## 📖 Сюжет
Тёмный лорд Морвейн похитил Священное Пламя Эльдории. Без него земля угаснет, а тьма поглотит всё живое. Вы — последний странник, способный вернуть свет. Соберите три Кристалла Света, найдите Старейшину и остановите Морвейна!

## 🕹️ Управление
* **WASD / Стрелки** — движение
* **Space / J** — удар мечом
* **E** — взаимодействие (диалоги)
* **R** — рестарт после победы или поражения
* **ESC** — выход

## 🚀 Как запустить локально
Если вы хотите запустить игру на своём компьютере:
1. Установите зависимости: 
   ```bash
   pip install -r requirements.txt
      ```
2. Запустите игру:
   ```bash
   python main.py
      ```
   
## 🛠️ Технологии
* **Python 3.12**
* **Pygame-CE** — игровой движок
* **Pygbag** — компиляция в WebAssembly для запуска в браузере
* **GitHub Actions** — автоматическая сборка и деплой веб-версии
